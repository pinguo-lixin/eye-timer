EyeTimer 1.0.1 修复版本，支持 macOS 13 及以上版本。

- 修复休息引导关闭后动画仍在后台运行、导致 CPU 持续偏高的问题。
- 修复重复关闭休息引导时重复触发回调的问题。
- 休息结束、手动跳过后会清理动画视图，再次休息时正常重建。

### 下载与安装

| Mac 类型 | 下载 |
| --- | --- |
| Apple Silicon（M 系列） | `EyeTimer-1.0.1-arm64.dmg` |
| Intel | `EyeTimer-1.0.1-x86_64.dmg` |

先退出 EyeTimer，再打开 DMG，将 EyeTimer.app 拖入 Applications（应用程序）替换旧版。设置和统计数据会保留。
ZIP 为备用下载方式，SHA256 文件用于核对下载完整性。

此版本尚未使用 Apple Developer ID 签名，也未经过 Apple 公证，首次打开可能被 macOS 阻止。安装及系统提示的处理方法见 [安装帮助](https://github.com/pinguo-lixin/eye-timer/blob/main/docs/install.md)。
