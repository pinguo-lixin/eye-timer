EyeTimer 首个公开版本，支持 macOS 13 及以上版本。

- Halo、Monolith、Paper 三种挂件样式，搭配雾蓝、暖砂、森林主题。
- 可拖动的桌面挂件，支持透明度调节、悬停提亮和原生右键菜单。
- 自定义专注与休息时长，提供休息引导、通知、提示音和语音提醒。
- 菜单栏倒计时、今日与近七天统计。
- 减少重复界面刷新，降低常驻 CPU 开销。

### 下载与安装

| Mac 类型 | 下载 |
| --- | --- |
| Apple Silicon（M 系列） | `EyeTimer-1.0.0-arm64.dmg` |
| Intel | `EyeTimer-1.0.0-x86_64.dmg` |

打开 DMG，将 EyeTimer.app 拖入 Applications（应用程序）。ZIP 为备用下载方式，SHA256 文件用于核对下载完整性。

此版本尚未使用 Apple Developer ID 签名，也未经过 Apple 公证，首次打开可能被 macOS 阻止。安装及系统提示的处理方法见 [安装帮助](https://github.com/pinguo-lixin/eye-timer/blob/main/docs/install.md)。
